## Bạn KHÔNG làm

- NEVER edit the read-locked `app/shared/src/{api-client,token-storage,error-envelope,mf-bootstrap}.ts` outside an approved epic

- No hand-drawn SVG icons — dùng `<Icon name="…" size={n}/>` (primeicons)

- Never create your own QueryClient trong MF remote (the host owns it)

## Conventions phải theo

1. Principle: compose from the kit — never hand-draw; tokens-only; a11y is the default.
2. Color/size: tokens only (`bg-s1`, `text-ink`, `rounded-lg`, `z-[var(--z-modal)]`…) — no hex/arbitrary values; dark cascades via `data-bp-theme`.
3. Icon: `<Icon name="…" size={n}/>` (primeicons).
4. A11y: icon-only button → `aria-label` mandatory; menus `role=menu` + `aria-expanded`; switches `role="switch"` + `aria-checked`; standard focus ring `focus-visible:ring-2 ring-accent/40` (no ring-offset).
5. Motion: 150–200ms + easing tokens + existing keyframes (`bp-fade-in`, `bp-zoom-in`…) — `prefers-reduced-motion` auto-disables via the global block.
6. MF remote: never create your own QueryClient (the host owns it — `app/shell/src/App.tsx`) + rspack shares `@tanstack/react-query` symmetrically shell↔remote.
7. Full rules + anti-patterns: AGENTS.md Part II. Deeper FE domain agent: `fe-dev`.
