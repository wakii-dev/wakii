# Context pack — FI-458 SF-3: Panel ⚙ Machines + worker ops

## Spec slice (chỉ phần SF-3)
- Worker op mới (main.mjs, pattern `verify-config`): `distributed-config` (get/merge-set
  vào distributed{} của story-kit.json, fail-open) + `claims-table` (gọi
  `story-launch --list-claims` — bin xuất claims JSON: sf, machine, at, stale) 
- Panel ⚙ Machines section: toggle distributed, input machine-id, host picker (danh
  sách từ `orca host list` qua worker), nút launch targeting (local vs host), bảng
  claims (sf | machine | age | stale highlight đỏ khi > TTL)
- Config contract: `distributed: { enabled, machineId, claimTtlMinutes, host }` — đồng
  bộ schema với SF-1

## Touch map
- main.mjs (worker ops — pattern `story.ops.request` action mới; DEF defaults)
- panel.html (⚙ Machines section — pattern GATE_KEYS + checkbox + save/poll đã có)

## ACCEPTANCE (user-visible / verifiable)
1. Bật distributed + đặt machine-id trong panel → story-kit.json ghi đúng, bins đọc được
2. Claims bảng hiển thị SF đang giữ bởi máy nào; claim stale > TTL tô đỏ
3. Launch targeting: chọn host → story-launch nhận --host đúng (log xác nhận)
4. Worker offline/Linear fail → panel hiện trạng thái, không crash

## Boundary
KHÔNG: sửa logic claim (SF-1 owns) · thêm daemon polling mới (dùng poll 3s/15s hiện có)

## Decisions chốt sau critic
- KHÔNG host picker (Direction C peer-model — --host là dead code, follow-up riêng)
- Fail-closed phân loại lỗi: thiếu key ≠ mạng chết ≠ parse fail — panel hiển thị reason
- Claims bảng derive Linear+git, KHÔNG đọc story.ops local (per-machine)

## Mode matrix (plugin hỗ trợ CẢ HAI — cùng 1 build)

| | OFF (1 máy, mặc định) | ON (đa máy) |
|---|---|---|
| ⚙ Machines section | Collapsed + CTA "Bật distributed" | Đầy đủ: machine-id + claims + targeting |
| Claims polling | OFF | ON (poll chu kỳ) |
| Launch | local không claim | claim → git-guard → fork |
| fail-closed | n/a | Linear fail → hiện reason, không launch |

Zero-diff: OFF là baseline — ON chỉ THÊM lớp phân tán, không đổi hành vi 1 máy.
Worker ops (`distributed-config`, `claims-table`) hoạt động cả 2 mode (get luôn
được; set/poll targeting chỉ khi ON).

## Render rules (claims bảng)

- 🟢 active: tuổi claim < TTL · 🟡 sắp stale: TTL → 2×TTL · 🔴 stale: ≥ 2×TTL (đủ điều kiện takeover — highlight đỏ)
- Cột: SF | Máy giữ (machine-id) | Tuổi claim | Trạng thái
- Nguồn: `story-launch --list-claims` (JSON) qua worker op `claims-table` — panel KHÔNG tự gọi Linear (closed transport)
- Refresh: poll chu kỳ có sẵn + nút ↻ thủ công (pattern Verify button)
- Lỗi phân loại hiển thị dưới bảng: "thiếu Linear key" ≠ "mạng chết" ≠ "parse fail"
- `distributed.enabled = false` → toàn section collapsed, chỉ còn toggle + CTA
