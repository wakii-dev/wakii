# Context pack — FI-458 SF-1: Claim core + distributed config

## Spec slice (chỉ phần SF-1)
- `story-launch` thêm flags: `--claim` (bật claim flow cho lần launch này),
  `--machine-id <id>` (mặc định hostname), `--host <host-id>` (SF-2 làm pass-through,
  SF-1 chỉ nhận + lưu config).
- Config `~/.claude/story-kit.json` thêm `distributed: { enabled: false, machineId:
  "<hostname>", claimTtlMinutes: 10 }` — đọc fail-open (thiếu file/key = defaults).
- Claim flow (khi enabled): với mỗi SF ứng viên launch — đọc claim hiện có trên
  Linear issue (comment mới nhất khớp `🤖 claimed by <machine-id> <iso-ts>` /
  assignee / label `claimed/<machine-id>`): (a) không claim → ghi claim → launch;
  (b) claim máy mình → launch tiếp; (c) claim máy khác + tươi (< TTL) → SKIP;
  (d) claim máy khác + stale (> TTL) và không có commit mới trong TTL → takeover.
- Heartbeat: story-launch ghi claim timestamp lúc nhận; takeover check commits-fresh
  (git log SF branch trong TTL) trước khi chiếm.
- Linear unreachable + enabled → FAIL-CLOSED (skip launch, log lý do); disabled →
  hành vi y hệt bản hiện tại (zero-diff).
- Race harness: 2 process chạy song song cùng claim 1 SF (fixture repo) → đúng 1
  thắng (test file tests/ có sẵn pattern process-spawn).

   với log "claimed by <other-machine>"
2. Claim stale > TTL + không commit mới → máy khác takeover thành công
3. Claim stale NHƯNG SF branch có commit mới trong TTL → KHÔNG takeover (commits-fresh)

5. Linear offline (SAI endpoint/env) + enabled → skip launch + log fail-closed, exit non-zero rõ ràng
